## Purpose and boundaries

This repository is a personal NLP reference index. It is not an approved model, dataset, production dependency set, or proof that listed methods are safe, licensed, current, or effective for a new domain.

- Papers, libraries, datasets, benchmarks, and tutorials retain source, date, version, license, language coverage, and maintenance state where practical.
- Datasets may contain personal, copyrighted, biased, confidential, or benchmark-contaminating material and require independent rights and privacy review.
- Benchmark results require exact task, split, metric, model, preprocessing, and date before comparison.
- Executable notebooks and packages require secret, dependency, malware, and supply-chain review before use.

## Required controls

- [ ] Run full-history secret, license, dead-link, dataset-rights, privacy, dependency, and provenance audits.
- [ ] Mark retracted, abandoned, stale, unsafe, or license-unclear resources.
- [ ] Separate descriptive references from executable code and downloadable datasets or models.
- [ ] Require language- and domain-specific validation before company adoption.

## Exit criteria

The repository is `REFERENCE_COMPLIANT` only when source, date, license, and data risks are visible, stale material is marked, and ownership remains intentionally personal.

The presence of this file alone is not endorsement.
